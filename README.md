# projeto_industria

Sistema de gestão de rendimento de matéria-prima voltado para serrarias e indústrias de móveis de pequeno e médio porte.

## Problema
A falta de controle sobre o desperdício de madeira bruta (toras ou chapas) durante o processo de corte. Este é um problema crítico que gera prejuízos financeiros invisíveis por ser controlado atualmente apenas em cadernos ou planilhas obsoletas.

## Tecnologias Planejadas
* Backend: Node.js (Express) / Banco de Dados Relacional
* Frontend: React.js / HTML / CSS / JavaScript
* Ferramentas: Git, GitHub e GitHub Projects (Metodologia Ágil/Scrum)
